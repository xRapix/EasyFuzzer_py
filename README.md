# EasyFuzzer

__EasyFuzzer__ is a Path Discovery Tool for pentesting websites. 

## Functions
  * Path Discovery
  * Easy to use
  * Ignore codes function


## Requirements

.py version:
  * Python 3.x or higher
  * Library _requests_ in python
  * Windows
.exe version:
  * windows

__Warning__: The .exe version can be detected as a virus by your anti-virus, so I recomend using the .py version

## How to use
1. Put your wordlist in the same folder as the script
2. start the script `python EasyFuzzer.py`
3. enter the Url
4. Enter the wordlist name
5. (optional) Enter Ignore codes
6. (deafult curl/7.68.0) Enter User-Agent
